# protengplus-frontend

React + TypeScript + Vite web client for ProtEngPlus. Talks to [proteng-bff](https://github.com/ProtEngPlus/proteng-bff) (`VITE_BACKEND_BASE_URL`) for auth, jobs, and results.

See [SETUP.md](./SETUP.md) to get it running locally, and [CONTRIBUTING.md](./CONTRIBUTING.md) for commit conventions and pre-commit hooks.
